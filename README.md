# Customer Shopping Behavior Analytics

## Project Overview

This project analyzes customer shopping behavior using Python, SQL, and Power BI. The objective of this project is to identify purchasing trends, customer preferences, revenue drivers, and business insights from customer transaction data.

---

## Tools & Technologies Used

- Python
- Pandas
- Matplotlib
- SQL
- Power BI

---

## Dataset Information

The dataset contains customer shopping transaction records including:

- Customer ID
- Age
- Gender
- Product Category
- Purchase Amount
- Payment Method
- Subscription Status
- Review Ratings
- Season
- Shipping Type

---

## Python Analysis

The following analysis was performed using Python and Pandas:

- Data Cleaning
- Missing Value Handling
- Exploratory Data Analysis (EDA)
- Data Visualization

### Visualizations Created

- Sales by Category
- Gender Spending Distribution
- Seasonal Sales Trend
- Age Distribution of Customers
- Payment Method Usage
- Top Purchased Products

---

## SQL Analysis

Business questions solved using SQL:

- Revenue Analysis
- Customer Segmentation
- Product Performance Analysis
- Subscription Impact Analysis
- Category-wise Sales Analysis

---

## Power BI Dashboard

The dashboard provides interactive insights including:

- Total Customers
- Average Purchase Amount
- Revenue by Category
- Revenue by Age Group
- Subscription Analysis
- Customer Spending Insights

---

## Key Insights

- Identified top-performing product categories.
- Analyzed customer spending patterns by age and gender.
- Evaluated seasonal purchasing behavior.
- Examined customer payment preferences.
- Explored the impact of subscriptions on spending habits.
